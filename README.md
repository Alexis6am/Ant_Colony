# Hormiguero

Proyecto simple hecho con Raylib.

## Ejecutar

Compila y corre el programa con:

```bash
g++ main.cpp -o app.exe -I C:/raylib/raylib/src -L C:/raylib/raylib/src -lraylib -lopengl32 -lgdi32 -lwinmm
./app.exe
```

## Requisitos

- Raylib instalado en `C:/raylib/raylib`
- MinGW o un compilador de C++ compatible
